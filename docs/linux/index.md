# Linux

Linux knowledge is essential for backend development, cloud infrastructure, DevOps, containers, and production troubleshooting. This chapter moves from the operating-system fundamentals to the commands used for files, users, permissions, processes, networks, monitoring, and storage.

## What Will You Learn?

| Section | Focus |
|---|---|
| **Fundamentals** | Linux architecture, distributions, environment setup, and package managers |
| **Filesystem** | The purpose of important directories under `/` |
| **Users** | Accounts, groups, passwords, and sudo access |
| **Files** | Creating, copying, moving, viewing, editing, and deleting files |
| **Vi Editor** | Navigation, editing, search, replace, and multi-file shortcuts |
| **Permissions** | Ownership, `chmod`, `chown`, `chgrp`, special bits, and `umask` |
| **Processes** | PIDs, signals, jobs, priorities, daemons, and `systemctl` |
| **Monitoring** | CPU, memory, disks, networks, and system logs |
| **Networking** | A practical command-based troubleshooting flow |
| **Storage** | Partitions, filesystems, mounts, LVM, and swap |

## How Should You Study This Chapter?

Read the sections in order if Linux is new to you. For interview revision, focus on what each command reports or changes, when administrative privileges are required, and which operations can permanently modify data.

:::tip Practice safely
Run ordinary inspection commands in a local Linux VM or disposable container. Use placeholder disks, users, paths, and process IDs carefully; do not run destructive storage or deletion commands against a real system without verifying the target.
:::
