# AWS Interview Guide

AWS interview preparation মানে service-এর নাম মুখস্থ করা নয়। একটি workload-এর requirements দেখে সঠিক compute, storage, database, networking এবং security option নির্বাচন করা—এবং সেই সিদ্ধান্তের cost, reliability ও operational trade-off ব্যাখ্যা করতে পারাই মূল লক্ষ্য।

## What you will learn

- Region, Availability Zone, VPC এবং shared-responsibility model-এর ভিত্তি
- EC2, Auto Scaling, Lambda, ECS ও EKS-এর উপযুক্ত use case
- S3, EBS ও EFS storage model এবং durability/availability trade-off
- RDS, Aurora, DynamoDB ও Redshift নির্বাচন করার reasoning
- IAM, monitoring, high availability এবং disaster recovery

## How to prepare

প্রতিটি service-এর জন্য চারটি প্রশ্ন practice করুন: এটি কোন problem solve করে, কখন ব্যবহার করবেন, কখন ব্যবহার করবেন না, এবং failure/cost কীভাবে handle করবেন। শেষে scenario chapter-এ request flow, security boundary, scaling trigger এবং recovery plan ব্যাখ্যা করুন।
